# 바텀시트 — IA FO-1 / FO-2 기준

집중 준비는 할 일·과목과 목표 시간을 설정하고 배 위 낚시를 시작하는 시트다. 집중 활동과 자리는 선택하지 않는다. 휴식은 집중 중 잠시 휴식 버튼으로 모닥불에 이동한다.

꽃나팔 방송기 건설 후 집중 화면에서 공동 음원을 선택한다. 그룹원 누구나 보유 음원을 바꾸며, 선택한 음원은 같은 섬에 공동으로 적용한다. 기기 음량만 개인 설정이다. 추가 ASMR은 상점에서 구매한다.

시간 버튼과 보유 음원은 UI 예시이며 실제 타이머·음원 재생·서버 변경은 수행하지 않는다. 기본 예시와 각 페이지에 포함된 팝업 템플릿을 함께 갱신했다.
