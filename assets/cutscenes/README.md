# 첫 항해 에셋

이 폴더는 현재 세션에서 새로 생성한 2D 컷신 에셋이다. 과거 모모·다른 동물 그림은 사용하지 않았다. Figma의 검정 고양이 그림은 디자인 기준이며 새 자세·분리 파츠를 Figma 원본으로 소개하지 않는다.

| 경로 | 용도 | 상태 |
| --- | --- | --- |
| `room-v2.png` | 첫 두 이야기의 방 | 기본 재생 |
| `shore-v2.png` | 부두·출항 | 기본 재생 |
| `sketch-beach.png` | 세 번째 이야기의 모래 스케치 | 기본 재생 |
| `coastal-home-pier.png` | 여정형의 집·길·부두 | 기본 재생 |
| `raft-deck-v3.png` | 같은 배경을 참고한 독립 뗏목 | 실제 투명 PNG, 기본 재생 |
| `sea-v2.png` | 별도 바다 배경 시험 | 전환 이음새 때문에 현재 미사용 |
| `sprites/black/` | 눈·걷기·승선의 생성 동작 | 기본 재생, 걷기 연속성 개선 중 |
| `rig-black/` | 머리·몸·앞발·꼬리 관절 실험 | 비교 중, 기본 재생 미채택 |

생성 과정은 [PROMPTS.md](PROMPTS.md), 렌더링·재검토는 [제작 하네스](../../docs/cutscene-production.md)를 따른다. 저채도·따뜻한 윤곽선·단정한 면을 기준으로 생성했으며 실제 제공 이미지의 해상도 이상을 네이티브 원화 품질이라고 부르지 않는다.

`sprites/black/manifest.json`과 `sprite-sheet-alpha.png`는 sprite-gen의 합성 출력이다. `source/`는 녹색 키 배경이 있는 생성 입력 보관본이며 직접 재생하지 않는다. `qa/*.gif`는 각 상태의 미리보기다. `frame_variant: pixel`은 도구가 내보낸 필드 이름으로, 그림 자체는 픽셀아트가 아니며 픽셀 언페이크를 적용하지 않았다.

검토 상태: blink는 상단 눈꺼풀→닫힘→열림의 형태를 확인했다. jump는 움츠림·도약·공중·착지의 4자세를 확인했지만 다른 동작과의 크기 연결을 개선 중이다. walk는 첫 결과의 반복 자세를 재생성했으나 아직 실험적 상태다. 자동 추출 성공을 움직임의 자연스러움 통과로 간주하지 않는다.
