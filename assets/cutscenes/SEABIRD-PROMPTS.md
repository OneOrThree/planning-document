# 먼 하늘 갈매기 후보

세션 이미지 생성으로 `shore-extended-v1.png`의 매끈한 2D 해안 스타일을 참고한 단일 갈매기를 만들었다. 배경 자체는 그리지 않고 초록 단색 위에서 날개를 편 활공 자세 한 마리만 요청했다. 따뜻한 짙은 윤곽, 크림색 등, 회색 날개 아래, 작고 자연스러운 몸체를 지시했다. 수채화·큰 눈·이모지·복제 새·텍스트는 제외했다.

요청한 진행 방향은 오른쪽 위였지만 실제 원화는 왼쪽 위를 향했다. 그림을 억지로 뒤집는 대신 비행 경로를 원화의 방향에 맞춘다. `seagull-glide-v1.png`는 1254 × 1254 RGBA이며 sprite-gen의 작동하던 cutout으로 분리했다. 완전 투명 픽셀 약 92.57%; 청록·자홍·노랑 검사판을 직접 확인했다.

배경의 먼 하늘에서 실제 날개 너비 약 28/19 논리 픽셀의 두 마리로 비교한다. 고양이·손·바다·육지에는 합성하지 않는다. 첫 여정형 배치는 화면 위로 잘려, 높이를 다시 등록했다. 현재 v16 MP4에는 없으며 별도 비교 후보로 남긴다. 단일 활공 원화의 기울기·경로 표현으로 날갯짓 또는 비행 물리 시뮬레이션은 아니다.
