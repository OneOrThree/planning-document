# 첫 항해 소품 생성 기록

세션 이미지 생성으로 만든 파생 소품이다. sprite-gen의 정상 작동한 cutout 단계로 실제 RGBA를 얻었다. 실제 화면에 연결하고 검토하기 전에는 완성·채택으로 표시하지 않는다.
