# 꼬리 국소 관절 후보

기준은 현재 사용하는 `poses-black/paddle-body-base-v1.png`다. 이전 캐릭터는 사용하지 않는다. 세션 이미지 생성으로 같은 고양이의 왼쪽 꼬리만 생성하고, 작동하던 sprite-gen `cutout --key green --white-check`로 단색 배경을 실제 알파로 분리했다. 스킬 오류를 디버깅하거나 재시도하지 않았다.

## 생성 지시

같은 1254 × 1254 캔버스에서 몸체·얼굴·다리를 모두 제거하고 왼쪽의 둥글게 말린 꼬리 하나만 남긴다. 기존의 굵기·곡선·따뜻한 짙은 윤곽선을 유지한다. 뿌리는 몸 뒤에 숨길 수 있도록 조금 연장한다. 새 캐릭터·복제 꼬리·글씨·배경 그림자 없이 균일한 초록 배경에 그린다. 수채화 대신 매끈한 2D 게임 에셋 윤곽과 절제된 음영을 쓴다.

## 결과와 등록

`poses-black/paddle-tail-layer-v1.png`: 1254 × 1254 RGBA, 완전 투명 픽셀 약 92.24%. 청록·자홍·노랑 검사판을 직접 확인했다. 요청했던 등록 위치와 실제 생성 위치는 달랐으므로 실제 뿌리를 읽고 코드에서 좌표·크기를 등록한다. PNG 원본을 재도색하거나 잘라 덮어쓰지 않는다.

털 중간값 `[113,89,92]`, 외곽선 R 중앙값 84를 같은 고양이 보정표에 등록한다. 색 자동 검사와 알파 불변 검사를 따로 수행한다. `cutscene-paddle-rig.js`는 기존 몸체에서 꼬리 영역만 런타임 마스크로 가리고 새 꼬리를 뒤에 합성한다. 얼굴과 몸 전체를 재생성하지 않는다.

현재 v15 MP4에는 없으며 별도 비교 후보다. 기본 채택 여부는 실제 연속 프레임 검토 후 기록한다. 전체 캐릭터 리깅이 아니다.
