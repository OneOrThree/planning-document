# v07 실제 MP4 표본 확인

9편 각각 12개 시점, 총 108개 디코딩 표본을 직접 확인했다. 캔버스 재렌더가 아니라 각 버전의 실제 MP4에서 추출했다.

- 검정 고양이·배경·짐·뗏목·자막이 9편의 출력에 유지된다.
- 세 이야기의 도입과 감정형·여정형·그림책형 장면 구성이 구분된다.
- v07의 짐 내려놓기 뒤 고개 들기와 2.2초 정리 구간이 출력됐다. 이 구간의 연속 동작 검토는 별도 `recovery-motion-v2`와 개선 기록 39에 있다.
- 보행 관절 실험은 이 영상에 포함하지 않았다. 보행과 도약의 연결은 후속 개선 대상이다.

이 확인은 출력 누락·깨짐과 장면 구성 점검이다. 전체 연속 동작의 통과 판정이나 별도 개선 회차로 더하지 않는다. `frames.json`의 자동 생성 상태는 검사 도구가 시각 승인을 대신하지 않도록 그대로 둔다.
