# v06 실제 MP4 표본 확인

9편 각각 12개 시점, 총 108개 디코딩 표본을 직접 확인했다. 캔버스를 다시 그린 캡처가 아니라 해당 버전의 MP4에서 추출했다.

- 방·모래·해안의 장면, 같은 검정 고양이, 뗏목과 자막이 출력에도 유지된다.
- 세 가지 이야기와 세 가지 연출의 도입·이동·출항이 구분된다.
- 검토 36~38의 감정형 전환, 국소 앞발 관절과 오른쪽 노 배치가 반영됐다.
- 책 내려놓기→고개 들기의 자세 전환과 보행·도약 연결은 후속 개선 대상이다.

이 확인은 출력 누락·깨짐과 장면 구성 점검이다. 전체 연속 동작 통과 판정이 아니며 별도 개선 회차로 더하지 않는다. `frames.json`의 자동 생성 상태는 검사 도구가 시각 승인을 대신하지 않도록 그대로 둔다.
