# v15 실제 MP4 확인

9편에서 각각 12개 시점을 디코딩한 순서표 108개 장면을 직접 확인했다. 캔버스를 다시 그린 결과가 아니다.

두 번째 이야기의 접힌 천은 승선 뒤에도 갑판 한쪽에 남는다. 부두 앞발 개선, 얼굴·털색 연결, 출항 카메라와 노의 화면 여유를 확인했다. 시간 간격이 큰 전체 순서표만으로 관절 움직임 전체를 승인하지 않는다. 동작 검토는 별도 cloth·dock 연속 프레임과 검토 54·55를 근거로 한다.

출력 당시의 3시점 × 84개 RGB 영역을 Chromium 디코딩과 비교한 2,268개 색 검사도 통과했다. 다른 재생기·모든 디스플레이의 색 인증은 아니다. 이 검사는 새 검토 회차로 더하지 않는다.

꼬리 분리 실험은 v15 출력 뒤 작업이므로 이 MP4에 포함되지 않는다.
