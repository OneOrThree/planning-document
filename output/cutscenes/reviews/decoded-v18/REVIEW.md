# v18 실제 MP4 확인

9편 모두 실제 MP4를 디코딩한 12개 시점, 총 108개 표본을 열어 확인했다. 같은 얼굴·책·가방·바다·노·꼬리·출항 구도를 유지한다. 추가로 출력 당시 3시점 × 84개 영역을 실제 디코딩 색과 비교한 검사를 통과했다.

24초·1080×1920·60fps·1,440프레임. v17의 연출을 직접 1/60초마다 다시 그린 것이며 보간 영상이 아니다. v18 원본에는 검토 59·60의 수면 반사·준비 눈 깜빡임이 없다.

앞선 동일 소스의 24/60fps 걷기·노 비교 각각 60개 연속 표본도 따로 보존한다. 해상도·프레임 속도 변경이나 이번 디코딩 검수는 새 미술 개선 회차로 더하지 않는다.
