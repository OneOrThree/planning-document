# v08 실제 MP4 표본 확인

9편 각각 12개 시점, 총 108개 디코딩 표본을 직접 확인했다. 각 버전의 실제 MP4에서 추출한 화면이다.

- 세 이야기의 도입과 감정형·여정형·그림책형 구성이 구분된다. 검정 고양이·배경·짐·뗏목·자막에 출력 누락이 보이지 않는다.
- 동일한 몸체와 분리한 다리로 걷는 새 보행을 출력했다. 발 접지와 관절 연결의 연속 표본은 개선 기록 40에 있다.
- 착지 시 발 기준점 보정과 3개 회복 포즈를 출력했다. 연속 동작 검토는 개선 기록 41에 있다.
- 몸체 회전·체중 이동이 충분한 완성형 전신 리깅은 아니다. 보행 중 눈 깜빡임과 바닥 접촉감은 다음 개선 대상이다.

이 확인은 실제 출력의 누락·깨짐과 장면 구성 점검이다. 24초 전체 연속 재생의 시각 승인이나 별도 개선 회차로 더하지 않는다. `frames.json`의 자동 생성 상태는 그대로 둔다.
