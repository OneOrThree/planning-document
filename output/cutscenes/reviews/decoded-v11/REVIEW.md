# v11 실제 MP4 확인

9편 각각 12개, 합계 108개 실제 디코딩 표본을 모두 열어 확인했다. `frames.json`의 지문·영상 SHA와 같은 출력이다.

- 34개 자세·파츠의 털색 보정, 나무 노, 같은 천 가방의 도입→걷기→갑판 연결이 인코딩 영상에 반영됐다.
- 세 이야기의 공책 내용과 준비 행동, 세 연출의 장소·자막·화면 구분이 유지된다.
- 모든 영상은 24초, 1080 × 1920, 24fps, 576프레임의 무음 MP4다. 브라우저 실제 재생과 Range 요청도 통과했다.
- 이 표본 확인은 출력 회귀 검증이며, 별도 개선 회차를 추가하지 않는다. 소품 접촉 연속 검토는 검토 45~47의 확대·연속 프레임 기록을 따른다.
- 다음 개선 대상은 노의 입수·복귀·물결 연결과 준비 자세의 작은 단계감이다. 모든 동작이 최종 승인된 것으로 표시하지 않는다.
