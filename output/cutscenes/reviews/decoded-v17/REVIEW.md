# v17 실제 MP4 확인

2026-09-12 KST. 아홉 영상 각각 12개, 총 108개 실제 MP4 디코딩 표본을 전부 열어 확인했다. 실시간 Canvas를 다시 그린 이미지가 아니다.

검토 58까지 반영한 갈매기 활공·노 주기 전진이 포함된다. 책→가방→부두→승선→출항의 순서와 9:16 구도를 유지하고, 낮은 채도도 출력 당시 RGB 기준으로 검사했다. 각 24초·24fps·576프레임·1080×1920이다.

60fps 시험과 수면 반사 후보는 이 배치에 없다. 원화 자세 교체의 세부 연결은 계속 개선 대상이며, 출력·디코딩 검사를 새로운 미술 검토 회차로 더하지 않는다.
