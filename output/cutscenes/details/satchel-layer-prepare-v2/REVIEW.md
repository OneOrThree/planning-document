# 검토 47 · 같은 책가방의 수납과 이동

결과: 네 레이어 가방을 기본 시연에 채택한다. 완성형 리깅 승인은 아니다.

- 직접 확인: 이 폴더 9편 × 18개 준비 표본, `satchel-layer-settle-v2` 9편 × 18개, `satchel-layer-walk-v2` 9편 × 12개.
- 직접 확인: `satchel-packing-motion-v2`의 첫 감정형 91개 연속 프레임, `satchel-settle-motion-v2`의 두 번째 여정형 57개 연속 프레임. 두 비교 MP4가 같은 시간표에서 출력됐다.
- 변경: 가방 몸체·손잡이·덮개 앞뒤의 동일 원화 계열, 입구 앞면의 별도 가림, 수납 완료 후 덮개 닫기, 낮춘 천 채도.
- 관찰: 책이 가방 앞면을 뚫지 않고 입구로 들어가며, 닫힌 가방이 걷기와 뗏목 정리까지 유지된다. 열린 덮개에 단추가 보이던 현상은 뒤쪽 천 면을 추가해 제거했다.
- 남은 한계: 개별 앞발 자세 교체, 세 번째 이야기의 가방 가져오기 동작. 자동 시간표 검사는 순서만 보장하며 미술적 자연스러움의 통과 판정이 아니다.

생성만 한 자료와 구분: 원화별 시안 검사판은 마젠타만 직접 확인했다. 다른 배경색의 검사판은 자동 생성 산출물이며 확인 횟수에 넣지 않는다. `satchel-layer-prepare-v1`과 `satchel-layer-settle-v1`은 첫 감정형 각 18개를 확인한 이전 시안이다.
