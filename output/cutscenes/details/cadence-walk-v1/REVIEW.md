# 24/60fps 실제 영상 비교

같은 소스 지문의 v17 첫 감정형 24fps 영상과 `cadence-60-study-v1` 60fps 영상을 비교했다. 걷기와 노 젓기 각각 1초, 60개 인접 시점을 실제 MP4에서 디코딩했다. `cadence-walk-v1`과 `cadence-paddle-v1`의 00~04 비교판을 전부 열었다.

24fps에서 같은 자세를 유지하는 사이의 작은 이동이 60fps에는 더 촘촘하게 들어간다. 그림의 모양·색·길이를 바꾸거나 완성된 24fps 영상에 프레임 보간을 한 방식이 아니다. 다음 출력은 60fps를 시험한다. 전신 자세 교체의 차이를 이것만으로 해결했다고 표시하지 않는다. 출력 속도 변경은 별도의 미술 검토 횟수에 더하지 않는다.
