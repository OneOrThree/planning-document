# 검토 50 · 영상 색 재현

9편 × 3시점의 Canvas / 이전 인코딩 / 수정 인코딩, 81개 패널을 모두 직접 열어 확인했다. 이 폴더의 54개 MP4는 각 0.5초 고정 장면 비교 자료이며 54편의 새 컷신으로 세지 않는다.

RGB 평균 절대 차이(0~255): 기존 10.0005 → 수정 1.9764. 수정된 27장면의 범위는 1.4823~2.2080이다. JPEG 및 H.264 손실 압축·색차 샘플링 때문에 무손실 동일이라고 표시하지 않는다.

채택: `tagged-srgb`. full-range JPEG의 601 계수를 limited-range 709 계수로 변환한다. 원화의 sRGB 전달 특성은 변환하지 않고 올바르게 기록한다. `setparams`를 마지막에 써 실제 프레임·파일에 primaries/transfer/matrix/range가 모두 남게 한다.

첫 비교(`mp4-color-profiles-v1`)와 태그 검토(`mp4-color-tags-v2`)도 각각 15개 패널을 모두 확인했다. 감마를 추가로 바꾸는 `managed-709` 후보는 이 브라우저에서 원본보다 어두워져 미채택했다. 태그만 설정하고 프레임 속성을 고정하지 않으면 일부 속성이 빠졌으므로 실제 ffprobe 결과를 확인한다.

완성본과 비교 영상은 `scripts/cutscene-video-profile.cjs`를 공유한다. v12까지의 기존 파일은 덮어쓰지 않는다. 같은 렌더 연출로 v13을 새로 출력해 재검증한다. 이 실험은 Chromium의 RGB 재디코딩 비교이며 모든 모바일 플레이어·디스플레이 인증은 아니다.
