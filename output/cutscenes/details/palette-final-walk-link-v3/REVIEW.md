# 색 연속성 검토 · 회차 44

서로 다른 자세의 생성 과정에서 색이 누적 이동했다. 원본과 cutout PNG의 동일 좌표 RGB는 같아, 알파 분리 과정의 색 변경은 원인이 아니었다.

세션 재생성 후보는 `TONE-MATCH-PROMPTS.md`와 함께 보존하지만 사용하지 않는다. 반감김 눈의 동공이 회색으로 변했고, 다리의 붉은 색은 수치상 더 커졌다. 최종안은 기준 검정 고양이를 유지하는 렌더 색 보정이다.

## 실제로 열어 확인한 범위

- 최종 v3 준비 9편 × 12, 걷기 진입 9편 × 12, 짐 정리 9편 × 18: 총 378개 표본.
- 첫 감정형 걷기 96개와 짐 정리 57개: 해당 구간의 모든 연속 프레임.
- 노 젓기 깜빡임: new-morning-emotion, folded-promise-journey, unfinished-pier-storybook 각각 12개. 다른 6편의 깜빡임 표본은 생성만 했으며 직접 검토로 세지 않는다.
- 이전 색 기준 표본 및 중간 v1·v2는 new-morning-emotion만 열어 확인했다. 생성한 모든 중간안을 검토했다는 뜻은 아니다.

털 중앙값은 RGB 77,69,69, 외곽선은 기준 원화의 중앙값 RGB 43,1,0에 맞췄다. SVG 색 채널 필터를 에셋 로드 시 오프스크린에 한 번 적용한다. 원본 PNG와 좌표·알파는 수정하지 않는다. 기준 중립 원화와 등록되지 않은 다른 캐릭터에는 적용하지 않는다.

`scripts/verify-cutscene-fur.cjs`는 30개 파츠의 알파 전체, 기존 중간톤 표본의 보정 후 중앙값, 외곽선·밝은 눈 흰자 변화를 실제 Chromium에서 검사한다. 이 수치 검사를 별도 시각 개선 횟수로 세지 않는다.

색 전환은 줄었지만 개별 자세의 윤곽 변화·단계감, 고정 상체 보행의 한계는 남는다. 화면 전체 연속 재생의 최종 승인도 아니다.
