# 덮개 접기 · 검토 54

실제 확인 범위는 두 번째 이야기의 세 연출이다. 이 폴더의 해당 3장, 총 36개 출항 표본을 확인했다. 나머지 6장 생성은 추가 검토로 계산하지 않는다.

- 각 연출의 `cloth-fold-*-v4` 38개 연속 프레임 전체를 확인했다.
- `cloth-boarding-emotion-v4` 50개 연속 프레임 전체를 확인했다.
- `cloth-boarding-all-v4`, `cloth-settle-all-v4` 각각 27개 개요를 확인했다.
- 앞선 v1~v2의 부두 이동은 천이 발 앞을 지나 미채택했다. v3의 갑판 모서리 배치는 너무 바깥이어서 v4에서 크기·위치를 조정했다.
- 접힘은 두 방향 격자와 생성된 접힌 천의 연결이다. 천의 질량·양손 상호작용을 계산하는 물리 리깅은 아니다.
- 최종 천은 갑판 모서리에 남아 승선 발·중앙 몸체·책·가방과 분리된다. 앞발의 자세 전환은 별도 개선한다.

중간 시험 출력 횟수와 자동 검사는 별도 개선 회차로 더하지 않는다.
