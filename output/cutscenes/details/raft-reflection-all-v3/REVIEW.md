# 수면 반사 v3 검토

9편 각각 12개 출항 확대 표본을 실제로 열어 확인했다. 첫 감정형과 세 번째 그림책형은 각각 adjacent-00~05, 총 72개씩의 수정 전후 연속 프레임도 확인했다.

v2 첫 세 편에서 자세한 갑판 윤곽이 물속에 복제되어 보였다. v3는 불투명도 0.10, 더 가까운 수면 기준, 작은 압축과 흐림으로 줄였다. 뗏목·노·고양이의 원래 움직임은 유지되고 반사는 바닥 아래에 옅게 머문다.

9편 × 4시점의 별도 수치 검사에서 수면 밖 픽셀 변경 0, 메타데이터 변화 0, 최대 채널 차이 19였다. 최초 렌더 캐시 차이는 반사를 끈 대조군에서도 재현되어, 같은 읽기 표면과 워밍업 뒤 비교한다. 이는 정지 표본·선택 연속 구간의 검토이며 광학 반사 시뮬레이션이나 모든 프레임의 최종 승인이 아니다.

검토 59에 채택. v18 영상은 이 변경 전 소스의 고정본이다.
