## 1. 섬 레벨 (D12 · D14)

- **P1.1** 🟢 레벨 산정 축 = **그룹 누적 집중 시간**(총량). 롤링 윈도우가 아니다 — **한 번 오른 레벨은 방치해도 내려가지 않는다**
- **P1.2** 🟡 단계 수 = **무한**. 상한을 두면 도달한 섬의 성장 동기가 사라진다
- **P1.3** 🟢 건물 해금은 **단방향**(D11). P1.1이 누적 총량이므로 실질적으로 하락 자체가 없지만, 향후 축이 바뀌어도 이 규칙은 유지한다
- **P1.4** 🟢 레벨 보상 = ① 건물 해금(3종) ② **섬 꾸밈 · 확장**. 해금 대상이 3종뿐이라 **꾸밈이 실질 주 보상**이다
- **P1.5** 🟢 **정원은 레벨과 무관하다.** "모닥불을 사서 정원을 늘린다"는 원안은 폐기(D13)
- **P1.6** 🟡 레벨 임계값(제안) — 곡선은 초반을 얕게, 이후 완만한 지수로

| Lv | 누적 집중 시간 | 해금 |
| --- | --- | --- |
| 1 | 0h | 기본 4종 |
| 2 | 20h | 꾸밈 1차 |
| 3 | 60h | 통계/랭킹 (안 ③이면 랭킹 탭) |
| 4 | 150h | 꾸밈 2차 |
| 5 | 300h | 소통 |
| 6+ | ×1.8 누진 | 꾸밈 · 건물 업그레이드 |

- **P1.7** ⚠️ **알려진 구조적 결과** — 누적 총량이므로 ① 오래된 섬은 아무도 집중하지 않아도 높은 레벨을 유지하고 ② 신생 섬은 선두를 따라잡을 수 없다. 수용 여부는 `open-questions.md` Q9

## 2. 재화 (D15 · D16)

- **P2.1** 🟢 재화는 **개인 지갑 + 섬 금고에 이중 적립**된다. 같은 집중이 두 축을 동시에 키운다
- **P2.2** 🟢 명칭 미정. 문서에서는 "재화"로 표기하고, 확정 시 전 문서 일괄 치환
- **P2.3** 🟢 **목표 달성 보너스는 gromo 공식을 그대로 승계**한다
  - 집중 목표: `clamp(floor(목표분/60), 1, 8) × 10` → 1h=10 … 8h 이상=80 (상한)
  - 폰 사용량 목표: 상한이 낮을수록 크다 — ≤60분 +80 / ≤120 +70 / ≤180 +60 / ≤240 +50 / ≤300 +40 / ≤360 +30 / ≤420 +20 / >420 +10
  - 원본: `server/data-api/src/main/java/com/oneorthree/phone/currency/service/CurrencyRewardPolicy.java`
- **P2.4** 🟡 시간 비례분(제안) = **집중 10분당 1개**. gromo에는 없던 축이다 — gromo는 목표 달성 1회 지급뿐이라 "목표를 못 채우면 0"이었다
- **P2.5** 🟡 개인 : 섬 금고 = **1 : 1**. 1시간 집중 → 개인 6 + 섬 6, 하루 목표 달성 → 개인 +10 / 섬 +10
- **P2.6** 🟢 원장은 gromo 구조를 승계한다 — `user_wallets`(낙관적 락) + `currency_transactions`(멱등키 unique). 섬 금고는 같은 패턴으로 신설
- **P2.7** ⚠️ **인플레이션 경보** — gromo는 소비처가 없어 미소비 유저 ≈100%, 구조적 인플레이션에 빠졌다(`docs/prd/currency/prd.md` §3.6). **상점(고양이 꾸미기 · 섬 꾸밈)이 출시와 동시에 열려야 한다.** 재화만 먼저 열지 않는다

## 3. 권한 (D19)

- **P3.1** 🟢 그룹장은 **전권**을 갖는다: 섬 설정 · 가입 승인 · 강퇴 · 퀘스트 생성/종료 · 공지 · **섬 금고 지출** · **기록 삭제**
- **P3.2** 🟢 이는 2026-08-27의 *"그룹장 3축 — 보상 분배권 명시적 제외"*를 **폐기하는 결정**이다 → `decisions-overridden.md`
- **P3.3** 🟢 그룹장이 탈퇴하려면 **먼저 위임**해야 한다. gromo의 `HOST_WITHDRAW` 가드와 `PATCH /groups/{id}/members/{uid}/owner`를 승계
- **P3.4** 🟢 마지막 1인이 나가면 섬은 종료된다(gromo `group.close()` 승계)
- **P3.5** 🔴 **잠수 그룹장 대응은 v2.** 전권 구조에서 그룹장이 접속하지 않으면 섬 금고·퀘스트·승인이 전부 멈춘다. 알려진 리스크 → `open-questions.md` Q2
- **P3.6** 🟢 강퇴된 사람은 재참여 불가(gromo `KICKED_CANNOT_REJOIN` 승계). 자진 탈퇴는 재참여 시 기존 행 부활

## 4. 퀘스트 · 자료 공유 (D20 · D21 · D22 · D23)

### 4.1 퀘스트
- **P4.1** 🟢 퀘스트는 **기존 gromo 챌린지 도메인을 그대로 사용**한다 — 판정 커널 `GroupBetJudge`, 요일 반복 비트마스크, 3상 판정(표시용 `null` vs 정산용 미달성), **내기·에스크로 포함**
- **P4.2** 🟢 지원 조합은 gromo와 동일 — `MissionCategory{FOCUS, SCREEN_TIME} × MissionType{DURATION, TIME_WINDOW}` 4조합
- **P4.3** 🟢 그룹당 활성 퀘스트 최대 4개, 목표 상한 FOCUS 1080분 / SCREEN_TIME 720분 (gromo 제약 승계)
- **P4.4** ⚠️ **폰 사용량 판정의 신뢰 경계** — 서버가 받는 것은 **하루 총 사용 분 하나뿐**이다. 앱별·카테고리별은 서버에 도달하지 않고, 해상도는 **15분**이며, **측정값은 클라이언트 보고를 신뢰한다**(위조 리스크 수용은 gromo `docs/prd/screentime/screentime.md` P5의 확정 정책). "측정을 끄면 이긴다"는 **권한 동의자만 진행분 대상**으로 막는다
- **P4.5** ⚠️ **내기 승계의 결과** — P3.1(전권)과 결합하면 **그룹장이 참가비를 강제**할 수 있고, 승자 0명이면 전액 몰수된다(gromo `FORFEITED`). 코지한 톤과 충돌 가능 → `open-questions.md` Q10

### 4.2 자료 공유
- **P4.6** 🟢 명칭은 **"자료 공유"**다. "숙제 제출"이 아니다
- **P4.7** 🟢 허용 형식 = **이미지 · PDF · 텍스트**
- **P4.8** 🟡 파일당 상한 **10MB**, 보관 **90일**
- **P4.9** 🟡 삭제 권한 = **작성자 + 그룹장**(P3.1 전권에 따라)
- **P4.10** 🟢 **신고 기능은 MVP 필수.** 앱스토어 UGC 정책상 사용자 생성 콘텐츠에는 신고 경로가 있어야 한다

### 4.3 검열
- **P4.11** 🟢 이미지 = **gromo의 OpenAI omni-moderation을 재사용**한다. fail-closed(키 미설정·타임아웃·5xx·파싱 실패 시 차단), 이미지 미저장, "유해 판정"과 "검사 불가"를 `unavailable`로 구분. 원본: `server/data-api/.../character/service/CharacterModerationService.java`
- **P4.12** 🟢 텍스트 = OpenAI text moderation **신규 추가**
- **P4.13** ⚠️ **PDF는 자동 검열이 불가능하다.** 신고 기반 사후 대응만 한다(D23). 첫 페이지 렌더링 검열은 서버 렌더링 인프라 대비 방어가 얕아 채택하지 않았다

## 5. presence · 집중 세션 (D24~D28)

- **P5.1** 🟢 동기화 단위 = **"누가 어떤 건물을 이용 중인가"**. 자유 좌표 동기화가 아니다
- **P5.2** 🟢 집중 중에는 **집중 공간 화면만** 열람할 수 있다(자기 앱 화이트리스트). 다른 탭·화면은 잠근다 — 집중 앱이 자기 앱 체류를 유도하지 않기 위한 경계다
- **P5.3** 🟢 presence 소비 경로 = ① 집중 공간 화면 열람 ② **iOS Live Activity**(잠금화면에서 곁눈질)
- **P5.4** 🟢 **하트비트 주기 = 1분.** 경로는 집중 공간 화면 열림 시 + 백그라운드 태스크(iOS BGTask / Android 포그라운드 서비스). Android는 차단용 포그라운드 서비스를 어차피 신설하므로(D4) ping을 얹는 비용이 낮다
- **P5.5** 🟡 하트비트 미도달 **5분** 후 "자리 비움"으로 표시한다
- **P5.6** 🔴 서버 orphan 타임아웃 단축은 **v2**. gromo 현행은 `endedAt IS NULL` + `startedAt > now - 12h`이고 방치 세션은 12시간 뒤 `AUTO_CLOSED`된다(`FocusService.ORPHAN_TIMEOUT`)
- **P5.7** ⚠️ **알려진 리스크** — P5.6 때문에 하트비트와 백그라운드 태스크가 **둘 다** 실패하면 **자리를 뜬 고양이가 최대 12시간 앉아 있을 수 있다.** 리그에서는 숫자만 틀렸지만 섬에서는 그림이 거짓말을 한다
- **P5.8** 🟢 이탈 처리는 **gromo와 동일**하다 — `totalDistractionSeconds`를 누적하고 세션을 무효화하지 않는다. 이탈 시간은 고양이 포즈로 표현할 수 있다
- **P5.9** 🟢 갱신 방식은 **폴링**이다. gromo가 이미 `FocusLiveInfo(focusTimeMinutes, isFocusing, focusStartedAt, focusTagName)`를 그룹 상세에 싣고 60초 폴링으로 돌린다. 웹소켓은 도입하지 않는다
- **P5.10** 🟢 집중 시간은 **세션을 시작한 섬에만** 귀속된다(D17). 고정 "주 활동 섬"이나 전환 쿨다운은 없다

## 6. 소통 (D29~D31)

- **P6.1** 🟢 편지 · 콕찌르기는 **UGC가 아니다.** 유저는 내용을 작성하지 않는다
- **P6.2** 🟢 편지 = **프리셋 문구 선택**. 발신자는 사람이고 내용은 서버가 소유한다. 그래서 텍스트 검열이 면제되면서 "누가 나에게 보냈다"는 감각은 남는다
- **P6.3** 🔴 **스티커는 v2**
- **P6.4** 🟢 콕찌르기 = 오늘 아직 집중하지 않은 그룹원에게 원터치 푸시. **하루 1회/인**
- **P6.5** 🟡 **개인 차단이 필요하다.** 내용이 정형이어도 하루 1회씩 계속 받으면 괴롭힘이다
- **P6.6** ⚠️ **알림 설정 갭** — gromo는 **전체 on/off + 야간 금지(23:00~07:00 KST)뿐이고 종류별 옵트아웃이 없다**(`UserNotificationSettings`). 편지·찌르기는 **종류별 수신 설정**이 필요하다 — 신규 구현

## 7. 온보딩 · 소속

- **P7.1** 🟢 첫 진입에서 **섬 생성 또는 기존 섬 참여**를 고른다
- **P7.2** 🟢 **개인 기능은 없다.** 혼자 쓰려는 사람도 섬을 하나 만들어 혼자 쓴다
- **P7.3** 🟢 한 사람은 여러 섬에 속할 수 있다. gromo 소프트 캡 `MAX_JOINED_GROUPS = 10` 승계
- **P7.4** 🟢 정원 제한 없음(P1.5)
- **P7.5** 🟢 가입 방식 = 공개 검색 참여 · 초대 링크 · **승인제**. **승인제는 gromo에 없어 신규 구현**이다(gromo는 공개=즉시참여 / 비공개=초대링크 / 선택적 비밀번호뿐)
- **P7.6** 🟢 초대 링크는 gromo 구조 승계 — `(그룹, 초대자)당 1링크 멱등 발급`, 링크 자체 만료 없음, deferred 매치 창 3시간

## 8. 랭킹

- **P8.1** 🟢 그룹 내 주간 랭킹 — 이번 주 집중 시간 순위. **매주 월요일 00:00 KST 리셋**(gromo `LeagueScheduler` 크론·주 경계 계산기 승계)
- **P8.2** 🟢 지난주 1위는 그 주 동안 고양이 옆에 왕관 배지
- **P8.3** 🟢 섬 간 랭킹 — **공식 순위는 1인당 평균**으로 한다. 총합은 참고 수치로 내린다
- **P8.4** ⚠️ P8.3의 이유 — D17로 집중이 세션 시작 섬에만 귀속되므로 총합 왜곡은 완화되지만, 총합을 나란히 보여주면 **사람은 큰 숫자를 순위로 읽는다.** 인원이 많은 섬이 자동으로 이기는 구도를 피한다
- **P8.5** 🟢 그룹 내 랭킹은 **gromo에 없다**(legacy 스텁뿐). 신규 구현
