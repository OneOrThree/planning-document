# 추가 IA 화면 이미지 시안

모드: 내장 `image_gen__imagegen`, 새 이미지 생성. 11장 모두 생성 후 직접 확인했고, 원본은 유지한 채 `assets/ia-references/`에 복사했습니다.

사용 방식: 화면 구도·색·여백·타이포그래피 참조. 클릭 가능한 텍스트와 컨트롤은 HTML로 다시 만들었습니다. 시안 속 서로 다른 섬·고양이는 기존에 선택된 마을 배경과 모모 원본으로 통일했습니다. ON-3의 이관 정책은 미확정이므로 시안의 확정형 문구를 구현에 사용하지 않았습니다. PO-4의 브라우저 권한 표현은 실제 네이티브 권한과 혼동하지 않도록 '앱 권한 미연결'로 수정했습니다.
