# 휴식 화면 명세 · 초안

GROMO-1862 반영 초안. 전체 화면 시안 30번(모닥불에서 쉬기)·31번(휴식 종료 · 이번 집중 결과)을 기준으로 정리했다.
상위 수치·정책은 [현재 정책](../policy-2026-09-14.md)을 따른다. 이 문서는 기능 인벤토리에서 휴식 화면과 세션 규칙의 상세 근거로 사용한다.

**번호 안내:** 아래 번호는 전체 화면 시안의 현재 순번 기준이다. API 스펙은 같은 화면을 26·27번으로 부르는 다른 체계를 쓰므로 번호 동기화는 별도 작업이다.

2026-09-16 결정 반영: 모닥불을 섬 화면과 분리된 전용 화면으로 못 박고, 나무 의자를 전부 없앴다. 휴식 동작을 책 읽기에서 **식빵 굽기**로 바꾸고 고양이 6색 에셋을 새로 만든다. 누적 집중 시간과 혼자 쉴 때 안내 문구는 화면에서 뺐다.

## 1. 화면 목록

| 번호 | 화면 | 비고 |
|---|---|---|
| 15 | 앵무새 안내 4 · 모닥불 | 온보딩에서 휴식을 한 번 소개한다 |
| 26 | 낚시섬에서 함께 집중 | 하단 버튼이 `휴식하기`·`집중 종료`다. 휴식 진입점 |
| — | 뗏목 이동 → 부두 도착 → 모닥불까지 걷기 | 화면이 아니라 전환 연출이다. 이 시간도 휴식에 포함한다 |
| 30 | 모닥불에서 쉬기 | **이 문서의 본 화면** |
| 31 | 휴식 종료 · 이번 집중 결과 | 결과창. 낚시섬 종료(29번)와 달리 귀환 항해가 없다 |

섬 홈에서 모닥불을 눌렀을 때 뜨는 모달은 이 문서 범위가 아니다(GROMO-1850). 이 문서는 **집중 중에 `휴식하기`를 눌러 들어온 화면**만 다룬다.

## 2. 모닥불 화면 구조 (30번)

휴식은 섬 지도 위에서 일어나지 않는다. **모닥불만 크게 보이는 전용 화면**으로 전환한다. 휴식 중인 주민은 섬 화면의 주민 목록·지도 위에 나타나지 않는다.

| 위치 | 내용 |
|---|---|
| 상단 | `휴식 중...` 한 줄 |
| 가운데 | 모닥불(낮에도 켜져 있음)과 그 옆 축음기. 모닥불 둘레에 식빵 굽는 고양이들 |
| 고양이 머리 위 | 그 사람의 휴식 경과 시간 `mm:ss` |
| 고양이 발 아래 | 그 사람의 이름 (긴 이름은 말줄임) |
| 하단 | `[집중 이어가기]` `[휴식 종료하기]` 두 개 |

화면에 **넣지 않는 것** — 나무 의자, 이번 집중 누적 시간, 낚은 물고기 수, 혼자 쉴 때의 안내 문구.

이름·시간은 그림에 굽지 않고 실시간 UI로 그린다.

## 3. 자리 배치

- 자리는 사용자가 고르지 않는다. 모닥불 둘레에 미리 잡아둔 자리 중 **빈 자리 하나에 자동으로 배정**된다. 서버가 `restSeat`(1번부터 차례로 빈 최소 번호)를 주고, 화면은 그 번호를 모닥불 둘레 좌표로 옮긴다.
- 의자는 없다. 고양이가 모래땅·풀밭에 바로 앉아 식빵을 굽는다.
- 먼저 쉬고 있던 사람의 자리와 타이머는 새 사람이 들어오거나 나가도 바뀌지 않는다(`고양이-모션-명세.md:69`).
- 누가 `집중 이어가기`를 누르면 그 고양이와 이름표만 사라진다. 빈자리는 그대로 남는다.

## 4. 휴식 시간 규칙

- **시작점은 `휴식하기`를 누른 순간이다.** 서버가 그 시각을 `restStartedAt`으로 저장한다. 뗏목 이동·부두에서 모닥불까지 걷는 연출 시간도 전부 휴식에 들어간다.
- 그동안 집중 세션은 **pause 상태**다. 유효 집중 시간(`activeSeconds`)이 늘지 않고 낚시 보상도 쌓이지 않는다.
- 이미 집중한 시간과 이미 낚은 물고기 수는 그대로 유지한다.
- 머리 위 타이머는 **이번 휴식의 경과 시간**이다. 이번 집중의 총 휴식 시간이 아니다. 휴식을 끝냈다가 다시 쉬면 `00:00`부터 센다.

## 5. 휴식 중 할 수 있는 것

| 행동 | 가능 | 비고 |
|---|---|---|
| 음악 바꾸기 | O | 축음기가 모닥불 바로 옆이라 이 화면에서 바꾼다 |
| 이모티콘 소통 | O | 지금 있는 5종(hello·cheer·sleepy·laugh·hearts)만 쓴다. 새 이모티콘은 만들지 않는다 |
| 채팅 | X | 집중 중 채팅 차단을 휴식에도 그대로 유지한다 |
| 집중 이어가기 | O | 낚시섬의 하던 자리로 돌아가 같은 세션을 이어간다 |
| 휴식 종료하기 | O | 이번 집중을 끝내고 결과창(31번) → 섬 화면. 귀환 항해 없음 |
| 섬의 다른 건물 들어가기 | X | 전용 화면이라 섬 조작이 없다. 건물에 가려면 휴식을 끝내야 한다 |

## 6. 상태별 차이

| 상황 | 화면 |
|---|---|
| 나 혼자 쉬는 중 | 내 고양이 한 마리만 모닥불 둘레에 있다. 별도 안내 문구 없음 |
| 여럿이 쉬는 중 | 각자 배정된 자리에서 식빵을 굽고, 각자 이름과 시간이 붙는다 |
| 다른 사람이 집중을 재개함 | 그 고양이와 이름표만 사라지고 나머지는 그대로 |
| 집중 세션 없이 모닥불을 구경 | 이 화면으로 오지 않는다 — 섬 홈의 모닥불 모달(GROMO-1850) 범위 |

- 기존 아트 규칙의 “모닥불에서 책 읽기” 결정
- 기존 고양이 모션 명세의 독서·의자·4자리 시연

## 8. 정책 미정 · 확인 필요

- **자리가 모자랄 때**: 섬 정원은 최대 15명인데 모닥불 둘레에 15명을 다 놓으면 붐빈다. 앞줄 몇 명만 그리고 나머지는 `+N명`으로 묶는 안을 임의로 생각해 뒀지만 확정된 결정이 아니다.
- **이모티콘**: 기존 세션 정책은 같은 섬의 **active** 집중 사용자만 응원 송·수신하도록 되어 있다. 휴식 중 허용이 이번 결정이므로 백엔드 정책과 정합성을 확인해야 한다.
- **채팅**: 같은 문서 FR-D04(「paused 상태에서 채팅을 허용할까?」)가 아직 미결이다. 이 문서의 "차단 유지"로 닫아야 한다.
- **휴식 중 앱을 끄거나 백그라운드로 보냈을 때**: GROMO-1902에서 정했다. 휴식 시간은 서버 시각 기준으로 계속 흐르고, 앱을 다시 켜면 이 화면으로 돌아온다. 휴식하기를 누른 순간부터 1시간이 지나면 서버가 이번 집중을 자동 종료해 정상 완료로 기록하고, 다음에 앱을 켤 때 결과창(31번)을 한 번 보여준다. 그 전까지 앱을 끈 주민도 다른 주민의 모닥불에 그대로 보인다. 원문은 [현재 정책](../policy-2026-09-14.md)이다.
- **`/screens/rest` 화면이 유지되는지**: GROMO-1785 코멘트는 "rest 화면 폐지, home이 `restMembers`를 함께 준다"고 하는데, 앱 저장소 현재 브랜치에는 그 근거(B15~B26)가 없고 `bff-screens/policy.md`에는 rest 화면이 살아 있다. 화면에 보이는 정보는 어느 쪽이든 같지만, 명세에 API 경로를 적기 전에 확인이 필요하다.
- **기존 독서 에셋 처리**: `reading/` 6프레임과 `preview/motion/rest-group.html`을 보존만 할지 폐기할지 정하지 않았다. `AGENTS.md` 규칙에 따라 지우지 않고 남겨 뒀다.
- **밤 배경**: 낮 배경 1장만 만든다. 밤 시간대 모닥불 화면은 아직 만들지 않았다.
