> **2026-09-16 4차 최종 복원:** 앞선 두 번의 롤백은 기준 버전을 잘못 잡아 취소했다. 현재는 실제 `before-hall-A-2026-09-16` 백업에서 회관 HTML·CSS·가로 화면을 그대로 복원했다. 회관 내부 책상의 미니섬·목각 건물·가계부는 유지되고, 섬 관리는 `섬 정보 / 가입 신청` 탭과 세로 정보 행, 2열 주민 카드가 있는 A안 적용 직전 버전이다.

> **2026-09-16 5차 개선:** 확정된 4차 복원본을 기준으로 방장·주민 역할 배지를 제거하고, 가입 승인은 ON/OFF 토글로 바꿨다. 섬 이름·소개는 본문에서 직접 편집하지 않고 작은 `섬 정보 수정` 입력창에서 함께 수정한다. 풀폭 `섬 초대 링크 공유` 버튼은 없애고 링크와 짧은 코드를 적은 점선 초대장 쪽지로 바꿨다.

> **2026-09-19 방문자 뷰 확정(GROMO-1904):** 다른 섬 방문자의 진입 방식과 마을회관·게시판 열람 범위를 정했다. 방문자는 회관 책상 없이 섬 정보 등록증만 보고, 주민 목록 바로 밑의 가입 버튼으로 가입한다. 방장 아바타의 왕관은 방장·주민·방문자 모든 뷰의 주민 목록에 표시한다(5차에서 없앤 글자 역할 배지는 그대로 두지 않고, 왕관이 방장 표시를 대신한다). 상세는 7번, 백엔드 권한 반영은 합의 대기다.

GROMO-1843 (항목 7·8·9) 반영 초안. 전체 화면 시안 42~60번(회관 책상~건물 청사진·주민 뷰) 및 딸린 서브스크린을 기준으로 정리했다.

## 4. 빈 상태 · 실제 0 (항목 9)

| 화면 | 상황 | 문구 |
|---|---|---|
| 48 가입 신청 | 대기 중인 신청 0건 | "기다리는 신청이 없어요 / 새 이웃이 신청하면 여기 보여요" |
| 52 공동 가계부 | 이번 달 내역 없음, 잔액 0(데이터 없음 아님) | 잔액 "🐟 0마리"를 실제 값으로 표시 + "아직 쌓인 내역이 없어요 / 주민이 함께 모으고 쓰면 여기 쌓여요" |
| 50 주민 | 방장 혼자뿐 | "아직 나뿐이에요. 섬 초대 링크로 같이 집중할 이웃을 불러보세요." 위임 대상이 없어 방장 위임 버튼은 노출하지 않고 섬 탈퇴만 남김 |
| 54 목각 건물 | 모든 건물(상점 포함) 완공 | 5개 카드 모두 "완공" 배지 |

## 5. 권한 없음 화면을 없앤 이유 (항목 6)

처음에는 주민이 47(가입 신청 관리)을 열면 "방장만 할 수 있어요" 권한 없음 모달을 보여주는 안이었다. 1차 리뷰에서 이 화면을 삭제했다 — 규칙상 주민은 방장 전용 화면에 애초에 진입하지 않으므로(진입 경로 자체가 없음) 권한 오류 화면을 따로 만들 필요가 없다는 지적이다. 대신 45·49(주민 뷰)에서 가입 신청 탭 자체를 목록에 넣지 않는 것으로 처리한다.

## 6. 정책 미정 · 확인 필요

- 다른 섬 방문자의 진입 방식과 마을회관 열람 범위는 2026-09-19 GROMO-1904에서 확정했다 — 7번 참고. 이 결정과 충돌하는 백엔드 권한 네 곳은 **백엔드 합의 대기**다.
- 50(방장 혼자뿐)에서 탈퇴하면 파괴적 확인을 거쳐 섬 공동 데이터를 삭제한다. 다른 소속 섬이 있으면 남은 메인 섬으로 이동하고, 마지막 소속 섬이면 계정·고양이·닉네임을 유지한 채 `04 · 혼자 시작 / 기존 섬 참여`로 이동한다. 상세 삭제 범위는 현재 정책을 따른다.
- 주민 뷰(45·49)에서 본인이 탈퇴하면 소속만 해제한다. 마지막 소속 섬이어도 막지 않으며, 다른 소속 섬이 있으면 남은 메인 섬으로, 마지막 소속 섬이면 `04 · 혼자 시작 / 기존 섬 참여`로 이동해 섬 만들기와 다른 섬 참가하기 중 고른다(2026-09-20 GROMO-1867).
- 56(모으는 중) 진행률·완료 표기 방식(체크마크 vs 숫자)은 임의로 정한 시안이며 API 응답 형태에 맞춰 조정이 필요하다.
- `정책-결정-2026-09-14.md` "목표 변경 시 이미 모은 몫을 새 목표로 이어서 셀지"는 여전히 추가 결정 필요 항목이라 55 화면에는 반영하지 않았다(목표 변경 UI 자체가 이번 범위 밖).

## 7. 다른 섬 방문자 뷰 (GROMO-1904)

2026-09-19 확정. **방문자**는 그 섬의 현재 활성 주민이 아닌 사용자다(가입 신청 대기자 포함). 기획 반영이며 앱 구현과 백엔드 권한 반영은 별도다.

### 진입

전망대 → 섬 찾기/랭킹 → '바다 건너 섬' 시트 → [배 타고 이동] → 그 섬 화면에 방문자로 도착한다.

| 항목 | 방문자 화면 |
|---|---|
| 내 고양이 | 섬에 표시하지 않는다 |
| 건물 누르기 | 걸어가는 연출 없이 바로 해당 화면이 열린다 |
| 돌아가기 | 화면에 `원래 섬으로` 버튼을 둔다 |
| 집중 시작 버튼 · 상단 '오늘 집중 시간' | 숨긴다 |
| 선착장 뗏목(내 배) · 모닥불 · 땅(섬 산책) | 눌러도 반응하지 않는다 |
| 상단 표시 | `소다 섬 구경 중`처럼 방문 중인 섬 이름을 작게 표시한다 |

### 마을회관 · 섬 정보 등록증

| 항목 | 방문자 화면 |
|---|---|
| 진입 | 42 회관 책상을 건너뛰고 바로 섬 정보 등록증이 열린다 |
| 등록증 내용 | 섬 이름·소개, `함께 사는 주민 N / 정원명`, 주민 목록(이름 + 고양이 아바타) |
| 방장 표시 | 프로필 사진(아바타)에 왕관을 씌운다 |
| 주민 카드 | 눌러도 프로필이 열리지 않는다 |
| 가입 버튼 | 주민 목록 바로 밑. 45 섬 정보 · 주민 뷰의 하단 `섬 탈퇴`와 같은 자리 |
| 공동 가계부 · 목각 건물(청사진) | 노출하지 않는다 |

방장 왕관은 방문자 뷰뿐 아니라 방장·주민 뷰를 포함한 모든 주민 목록에 표시한다. 5차에서 제거한 글자 역할 배지 자리를 왕관이 대신한다.

### 가입 버튼 상태

| 상태 | 버튼 |
|---|---|
| 승인 불필요 + 자리 있음 | `이 섬에 가입` → 즉시 주민이 되고 방문자 상태가 끝나 이 섬이 현재 섬이 된다 |
| 승인 필요 + 자리 있음 | `가입 신청` → "참여 신청이 완료됐어요. 방장이 확인하면 알려드릴게요." 토스트, 계속 방문자 |
| 신청 대기 중 | `신청 취소` |
| 정원 마감 | 버튼 비활성 + "정원이 가득 찼어요" |

### 게시판 · 나머지 건물

| 장소 | 방문자 |
|---|---|
| 게시판 | 공지·댓글·퀘스트(퀘스트 자세히 보기의 주민별 달성률 포함)를 읽을 수 있다. 공지·댓글·퀘스트 작성은 불가. 댓글 입력창 자리에 "주민이 되면 댓글을 남길 수 있어요" 안내 문구를 둔다. 게시판이 미완공인 섬은 방문자에게도 게시판이 없다 |
| 축음기 · 도서관 · 우체통 · 전망대 · 상점 | 누르면 "주민만 이용할 수 있어요" 토스트만 뜬다 |

비공개 섬: 2.0 정책에는 섬 공개/비공개 설정이 없으므로 모든 섬을 공개로 보고 비공개 상태별 차이는 두지 않는다.

### 방문자에게 노출하지 않는 것

가입 신청 관리, 주민 관리(강퇴·위임), 초대 링크, 섬 정보 수정, 공동 가계부, 목각 건물·청사진, 게시판 작성, 주민 개인 기록(집중 시간 등). 단 게시판 퀘스트의 주민별 달성률은 예외로 공개한다.
