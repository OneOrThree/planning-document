# Catus 법률 문서 앱 반영·출시 체크리스트

이 문서는 GROMO-1869 완료조건 6을 앱 PRD와 구현 작업으로 넘기고, 정본 공개 전 필요한 증거를 모으는 방법을 정한다. 체크 표시에는 문구 채택이 아니라 실제 링크·설정·기기 검증 근거가 필요하다.

## 1. 정본 확정

- [ ] Sentry·Datadog·FCM·PostHog와 배포 인프라의 수탁 법인, 처리 국가·지역, 이전 방법, 보유기간을 확인한다.
- [ ] 신고 기록, 최소 계정 식별키, 구매·정산 근거, 동의 증명의 보유기간과 법적 근거를 확정한다.
- [ ] 한국어 정본을 확정한 뒤 영어·일본어로 번역하고 법률 의미가 같은지 검수한다.
- [ ] 버전, 시행일, 공개 URL과 변경 전후 비교 내역을 확정한다.

## 2. 앱 PRD 반영

| 기능 ID | PRD에 넣을 요구사항 | 완료 증거 |
| --- | --- | --- |
| A02 | 게스트를 포함해 계정 생성 전에 만 14세 이상·이용약관·필수 개인정보 항목을 각각 확인한다 | 가입 화면 영상, 거부 상태 테스트, 동의 API 기록 |
| A03 | Catus가 GroMo와 계정·데이터를 이전하지 않는 별도 앱임을 필요한 진입점에서 알린다 | 화면·문구 검토 |
| A09 | 섬 탈퇴와 회원 탈퇴를 구분하고 삭제·연결 해제·보존 범위를 전문에서 연다 | 탈퇴 화면, 삭제 작업·감사 로그 테스트 |
| D01 | 첫 집중의 할 일 입력란에 같은 섬 주민 공개와 민감 내용 입력 주의를 상시 표시한다 | 작은 화면·접근성 기기 QA |
| D18·O02 | 스크린타임과 앱별 사용 시간 동의를 분리하고 동의 뒤에만 OS 권한을 요청한다 | 동의 조합별 E2E, 서버 전송 검사 |
| B01·B09 | 첫 섬 생성·가입 확정 전에 섬 기록 공개 카드를 확인받는다 | 미확인 가입 차단 테스트, 고지 버전 기록 |
| O07 | 게시물 삭제 시 첨부파일을 삭제하고 백업 사본은 최대 7일 안에 만료한다 | 저장소 이벤트·백업 만료 증거 |
| O08 | 약관·처리방침·필수 수집·공개 고지·선택 동의를 분리하고 최신 전문 링크와 동의 버전을 저장한다 | 링크·언어·버전·철회 E2E |
| I08 | 신고·차단과 이의 제기 경로를 제공한다 | 차단 필터·신고·해제 테스트 |

앱 PRD에서 `decision: chosen`과 `proof: pending`을 그대로 구분한다. 이 표를 복사했다는 사실만으로 `proof`를 바꾸지 않는다.

## 3. 문서 노출 위치

1. 계정·게스트 생성 전: 이용약관 전문, 필수 개인정보 수집·이용 요약, 개인정보처리방침 링크
2. 첫 섬 생성·가입 전: `섬에서 함께 보이는 기록` 고지와 확인
3. 스크린타임·앱별 사용 시간 최초 사용 전: 각각의 선택 동의와 OS 권한 순서
4. PostHog 일반 분석·Session Replay 시작 전: 각각의 선택 동의
5. 앱 설정 또는 내 정보: 최신 약관·처리방침·동의 상태·철회·권리행사·회원 탈퇴
6. 공식 사이트: 한국어·영어·일본어 정본과 이전 버전·변경 내역

## 4. 데이터·SDK 검증

- [ ] 소셜 로그인에서 제공자 고유 ID 외 이메일·프로필 이름을 저장하지 않는다.
- [ ] 차단·허용 앱 목록은 기기 밖으로 전송하지 않는다.
- [ ] 하루 총 스크린타임만 같은 섬 도서관에 보이고 앱별 사용 시간은 타인에게 보이지 않는다.
- [ ] PostHog 일반 분석·Replay는 각 선택 동의 전 네트워크 요청이 없다.
- [ ] Replay의 텍스트·입력값·이미지가 실제 기기에서 모두 가려진다.
- [ ] Sentry·Datadog·PostHog에는 내부 UUID만 전달하며 닉네임·소셜 제공자 ID·이메일을 보내지 않는다.
- [ ] 로그아웃·탈퇴 시 SDK 사용자 문맥과 FCM 토큰 연결을 지운다.
- [ ] 탈퇴 처리 중 앱별 사용 시간 원본과 직접 식별정보를 삭제하거나 연결 해제한다.
- [ ] 공동 콘텐츠 작성자 연결 해제, 게시물·첨부파일 동시 삭제, DB 백업 7일 만료를 검증한다.
- [ ] 법정·운영 보존 데이터의 접근 제한과 기간 만료 삭제를 검증한다.

## 5. 동의·권리행사 검증

- [ ] `userId/guestId`, 항목 종류, 문서 버전, 동의·철회 시각, 언어, 앱 버전·플랫폼을 서버에 남긴다.
- [ ] 선택 동의는 기본 선택하지 않고 항목별로 철회할 수 있다.
- [ ] 선택 동의를 거부해도 집중·섬 활동이 동작하고 사용량은 `0분`이 아닌 `권한 없음`으로 표시된다.
- [ ] 공개 대상·항목이 넓어지면 고지 버전을 올리고 다음 관련 기능 진입 전에 다시 확인받는다.
- [ ] 이메일과 앱 경로에서 열람·정정·삭제·처리정지·동의 철회·회원 탈퇴를 요청할 수 있다.
- [ ] 요청 거절·제한 시 사유와 이의 제기 경로를 안내한다.

## 6. 공개와 회귀 검증

1. 운영값과 앱 구현이 문안과 일치하는지 확인한 본문을 버전 고정한다.
2. 세 언어 문서를 공식 사이트에 게시한다.
3. 앱의 모든 전문 링크가 실제 공개 URL과 버전을 연다.
4. `npm run check`, `npm test`, `npm run build`를 실행한다.
5. Pages의 `/planning-document/docs/legal/` 하위 링크를 확인한다.
6. 앱 기기 QA, 네트워크 캡처, 삭제 작업 결과와 외부 도구 설정 화면을 구현 증거로 연결한다.
