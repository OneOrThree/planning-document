## 공개 전 차단 항목

다음 항목이 끝나기 전에는 두 정본 후보를 `시행 중`으로 표시하지 않는다.

1. Sentry·Datadog의 실제 수탁 법인, 처리 국가·지역, 보존기간 확인
2. FCM과 배포 인프라를 포함한 전체 수탁자·국외 이전 목록 확인
3. GROMO-1757 탈퇴 삭제·연결 해제 배선과 첨부파일 삭제·백업 7일 만료 검증
4. PostHog 미국 리전, 원시 IP 미저장, 전체 마스킹, 선택 동의 설정의 운영 증거 확보
5. 시행일·공개 URL 확정과 한국어·영어·일본어 최종 번역 검수
6. 앱 안의 약관·처리방침 링크, 동의 버전 저장, 철회·권리행사 경로의 기기 QA

## 완료조건 판정

| GROMO-1869 조건 | 판정 | 근거 |
| --- | --- | --- |
| 4. 개인정보처리방침·이용약관 정본 작성 | **완료** | 한국어 정본 후보 2개 작성 |
| 6. 확정 정본 공개와 앱 PRD 반영 | **기획 전달 완료 / 공개·앱 구현 대기** | 앱 반영·출시 체크리스트와 O08 연결 |

기존 GroMo 사용자 고지·재동의는 완료조건에서 삭제했다. Catus는 GroMo와 계정·데이터를 이전하지 않는 별도 신규 앱이라는 제품 결정만 유지한다.

## 작성 기준

- 개인정보 처리방침은 개인정보 보호법 제30조의 필수 항목을 기준으로 구조화했다.
- 계약 이행에 필요한 처리와 선택 동의 처리를 구분했다.
- 기기 안에서만 처리하는 차단·허용 앱 목록도 서버 미전송 사실과 삭제 기준을 알렸다.
- 국외 처리위탁은 실제 계약·리전이 확인된 값만 단정한다.
- 이용약관의 중요한 제한은 가입 전에 쉽게 읽고 전문을 열 수 있어야 한다.
