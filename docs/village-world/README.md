# 타일 마을 · 개발 미리보기

[시연 열기](../../village-world.html) · [디자인 작업실](../../index.html)

## 상태

2026-09-23 사용자가 v4 흙길 시안을 기획 작업실과 앱 개발 미리보기에 연결하도록 승인했다. **구조와 개발 적용 방향은 채택**, 최종 미술·실기기 성능·기본 화면 전환은 검토 중이다. HTML은 시연이며 앱 출시 완료를 뜻하지 않는다.

## 함께 보는 것

- 빈 지형 → 풀·꽃 → 마을 단계 비교, 32/64/128px 타일 분할.
- 풀·꽃·나무·모닥불·시설 109개를 독립적으로 배치.
- 부드러운 흙길과 건물 문 앞 샛길, 실제 통행 가능한 부두·다리.
- 길을 우선하는 고양이 이동, 건물 앞뒤 가림, 모닥불과 바람 연출.
- 배치 모드와 다운로드는 검토 도구다. 앱 사용자용 꾸미기·저장 기능은 이번 범위가 아니다.

## 정본과 내보내기

- `village-world.html`, `village-world.css`, `village-world.js`: 시연 원본.
- `assets/village-world/`: 빈 지형, 소품 원본, 걷기 프레임, 복원한 다리.
- `assets/village-world/export/map.json`: 앱 전달용 배치·문 좌표·이동 폴리곤·길 정보.
- `assets/village-world/export/*.png`: 투명 소품과 시설별 길 레이어. 원본 좌표에 맞춘 잘라낸 그림.
- `node scripts/export-village-world.cjs`: 임시 서버에서 시연을 열고 앱용 파일을 재생성한다.

앱은 지형을 합친 한 장과 개별 소품·길 레이어를 사용한다. 타일 좌표는 데이터로 유지한다. 시설 ID는 `hall`, `board`, `gram`, `library`, `mail`, `tower`, `shop`이며 건설된 시설의 그림·샛길·충돌만 적용한다.

## 에셋 출처

- 기존 섬: `assets/gachisup-r61/island/base/day.png`.
- 기존 건물·고양이: Catus 앱과 기획 작업실의 공유 아트. 앱 구현 소스는 포함하지 않는다.
- 부두: `assets/gachisup-r61/props/dock/layers/`의 앞뒤 그림을 합성.
- 빈 지형·자연 소품·다리: 이 작업에서 생성한 파생 아트. [생성 기록](generation.md).
- 흙길: Canvas 곡선과 절차적 질감. 32px 길 정보와 분리된 투명 레이어.

## 남은 검토

문·충돌 영역은 발밑 근사치다. 임의로 밀집 배치하면 길이 시설과 겹칠 수 있고, 해안 가까이 옮기면 잘릴 수 있다. 밤은 시연용 색 필터다. 섬 전체가 반복 가능한 지형 타일셋은 아니다.

## 작업·검증 기록

- v1: 원화를 128px 조각으로 분할하고 이동 실험.
- v2: 빈 지형 + 독립 소품, 기본 64px.
- v3: 순환 길·샛길·길 우선 이동.
- v4: 길 폭 축소, 불규칙한 경계와 흙·잔디·돌 질감.
- 개발 연결: 기획 시연 공개 준비, 부두·다리 복원, 시설별 길 분리, 앱 개발용 전환 연결.
- 관련 작업: GROMO-2094. 검증 결과는 이 문서 아래에 이어 기록한다.

### 2026-09-23 검증

- 기획: `npm run check`, `npm test` 통과. 추가한 `scripts/verify-village-world.cjs`에서 프로젝트 하위 경로 로딩, 32px 1,536개 분할, 시설 문·부두·작은 섬 10개 경로, 부두·다리를 포함한 ZIP 다운로드를 확인했다.
- 배포: 이번 변경만 포함한 깨끗한 사본에서 `npm run build` 통과, 약 956.6 MB. 기존 로컬 미커밋 영상·에셋까지 포함한 작업 폴더 빌드는 1 GB 제한을 넘으므로 검증 대상을 분리했다. 다른 작업물은 삭제하지 않았다.
- 앱: 타입 검사, 포맷/팔레트 검사, ESLint 오류 0개, Jest 59개 묶음·741개 테스트 통과. 웹·iOS·Android용 JavaScript 번들 생성 통과.
- 앱 브라우저: 세로 402×874·가로 874×402에서 시설 7개·길 레이어 8개, 구·신 마을 전환, 시설/부두 진입, 빈 섬·시설 일부 건설 상태를 확인했다. 화면 오류와 깨진 이미지 없음.
- 앱은 현재 QA 정책상 내 섬의 시설을 전부 완성하므로 건설 단계 렌더링은 구경할 섬과 이동 단위 테스트로 확인했다.
- 실기기 GPU·메모리·프레임 속도, iOS/Android 네이티브 실행은 아직 검증하지 않았다. 번들 생성 성공과 구분한다.
