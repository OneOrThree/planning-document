opening film / reproducible asset record

컷신 제작
프롬프트

생성 원화, 배경, 소품, 분리 파츠를 다시 만들거나 고칠 수 있도록 실제 사용 문장과 채택 범위를 한곳에 모았습니다.

먼저 알아둘 점. 아홉 편은 텍스트-투-비디오 결과물이 아니라, 생성한 2D 원화·배경·소품을 Canvas와 코드로 조합해 렌더한 영상입니다. 따라서 여기에는 영상 생성 프롬프트가 아니라 컷신에 쓰인 이미지·스프라이트·파츠 생성 프롬프트가 기록됩니다.

목차

기록의 범위주요 원화·배경걷기·동작소품·환경분리 파츠·리그

재현 가능한 원화 기록

프롬프트는 원문 그대로 표시합니다. 생성 실패·체크무늬 배경·실험 파츠는 채택 에셋과 구분하며, 출력물이 실제 알파인지 여부는 별도 QA 기록으로 확인합니다.

채택 또는 현재 기준비교·보류 중이전안 또는 미채택

프롬프트 원문은 저장소의 Markdown도 함께 보존합니다. HTML 뷰가 열리지 않는 환경에서는 각 원문 링크를 열면 됩니다.

도구 기록: 원화 생성은 세션 내 이미지 생성 도구를 우선 사용했고, `sprite-gen`은 분리·아틀라스·미리보기 보조에 사용했습니다. 생성된 동작·파생 전신은 Figma 원본과 구분합니다.
