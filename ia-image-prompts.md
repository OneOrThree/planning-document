# IA 화면 이미지 제작 기록

내장 image generation tool 사용. 원본 UI와 모모는 스타일·정체성 참고 이미지로 제공했다. 생성 이미지는 편집 가능한 화면의 참조이며, 앱에는 기존 일관된 섬·캐릭터 에셋과 실제 HTML 컨트롤을 사용한다.

ON-3의 생성 문구는 이전 확정을 암시해 채택하지 않았다. 실제 구현은 정책 Q1에 맞게 승계 범위를 확인 중이라고 명시했다. 섬 이름/재화 단위/가격 등 수치는 시연값이며 정식 정책 확정이 아니다.
